# Trello-like Kanban Board

A beautiful, modern kanban board application inspired by Trello. Built with React, Vite, and react-beautiful-dnd.

## Features

- 📋 **Multiple Boards** - Create and manage multiple kanban boards
- 📝 **Lists & Cards** - Organize tasks into lists and cards
- 🎯 **Drag & Drop** - Intuitive drag-and-drop functionality to move cards between lists
- ✏️ **Edit in Place** - Click on any card or list title to edit
- 💾 **Local Storage** - All data is automatically saved to your browser's local storage
- 🎨 **Modern UI** - Beautiful, responsive design with smooth animations

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Usage

1. **Create a Board**: Click "New Board" and enter a name
2. **Add Lists**: Click "+ Add another list" to create new columns
3. **Add Cards**: Click "+ Add a card" in any list to create a new card
4. **Edit**: Click on any card or list title to edit
5. **Drag & Drop**: Click and drag cards to move them between lists or reorder within a list
6. **Delete**: Click the × button on cards, lists, or boards to delete them
